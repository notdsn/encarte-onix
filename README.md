# Encartes Ônix

Gerador de encartes de promoção das **Drogarias Ônix**. App estático, feito para usar no celular (Safari ou Chrome) ou no computador.

**Endereço:** https://notdsn.github.io/encarte-onix/

## Como usar

1. Abra o link no celular ou no computador.
2. Escolha o formato: **Story/Status** (9:16), **Feed** (1:1) ou **A4** para impressão.
3. Escolha um tema (Clássico Ônix, Relâmpago, Farmácia clean ou Noite Ônix).
4. Preencha o título, o período de validade e, se quiser, endereço, WhatsApp, Instagram e o logo da loja.
5. Adicione até 12 produtos com nome, detalhes, preços de/por, foto e selo (ex.: “Leve 3 pague 2”).
6. Toque em **Baixar PNG**, **Compartilhar** (quando o celular permitir) ou **Imprimir / PDF**.

Os dados ficam salvos neste navegador. Use **Exportar JSON** para fazer um backup (incluindo as fotos compactadas) e **Importar JSON** para restaurar.

## Observações

- Endereço, WhatsApp e Instagram começam vazios para você preencher.
- O percentual de desconto é calculado automaticamente quando existem os dois preços.
- O aviso legal do rodapé pode ser editado.
